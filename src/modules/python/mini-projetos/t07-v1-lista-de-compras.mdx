# Lista de compras

## Contexto
Você está montando a lista de compras da semana para a casa e precisa manter o controle de forma simples. A lista precisa aceitar itens novos, remover itens errados, mostrar tudo em ordem e limpar tudo quando a compra for finalizada. Como o problema é pequeno, uma lista em Python resolve bem, mas precisa ter atenção para não perder itens ou apagar a lista inteira sem querer.

## O que você vai construir
Um programa que mostra um menu com opções para adicionar, remover, listar e limpar itens da lista de compras. O objetivo é manter a estrutura simples e prática, sem perder o controle do que já foi comprado.

## Requisitos
1. Exibir um menu com opções claras para o usuário.
2. Permitir adicionar itens novos na lista.
3. Permitir remover um item informado pelo nome.
4. Listar todos os itens atuais em ordem.
5. Limpar a lista quando a compra for finalizada.
6. Encerrar o programa quando o usuário finalizar a operação.

## Critérios de aceite
- [ ] O menu sempre aparece para o usuário escolher a próxima ação.
- [ ] A lista aceita itens repetidos quando a regra permitir, e você consegue remover o item correto.
- [ ] A opção de listar mostra todos os itens em ordem de cadastro.
- [ ] A limpeza da lista é explícita e não acontece por acidente.
- [ ] O programa não quebra quando a lista estiver vazia.
- [ ] O aluno consegue explicar como usar `append`, `remove` e `clear` em contexto real.

## Guia
### Etapa 1: montar o menu
- Use `while True` para manter o programa ativo até o usuário sair.
- Exiba as opções em sequência para facilitar a leitura.
- O menu é o centro do fluxo; ele decide qual ação executar em cada iteração.

### Etapa 2: adicionar itens
- Leia o nome do item com `input()`.
- Remova espaços extras com `.strip()` para evitar itens vazios.
- Use `append()` para guardar o produto na lista.

### Etapa 3: remover itens com cuidado
- Antes de remover, verifique se a lista não está vazia.
- Se o item existir, use `remove()`. Se não existir, mostre uma mensagem útil.
- Lembre-se de que a lista é mutável; o programa altera o conteúdo em memória, então precisa controlar essa mudança com atenção.

### Etapa 4: listar e limpar
- Para listar, percorra a lista com `for` ou `enumerate`.
- A opção de limpar pode usar `clear()`, que apaga todos os itens de uma vez.
- Use mensagens claras para o usuário saber se a ação foi bem-sucedida.

### Etapa 5: refletir sobre cópia vs referência
- `lista_b = lista_a` faz duas variáveis apontarem para a mesma lista.
- `lista_b = lista_a.copy()` ou `lista_b = lista_a[:]` cria uma cópia separada.
- Isso é importante quando você quer manter uma lista original e trabalhar em uma cópia para testar, filtrar ou comparar.

<Callout type="importante" title="Dica da etapa 5">
Em listas, não confunda “nome da variável” com “conteúdo da lista”. Se duas variáveis apontam para a mesma lista, alterar uma também altera a outra. Isso é um dos erros mais comuns ao trabalhar com coleções.
</Callout>

```python
lista = []

while True:
    print("=== Lista de compras ===")
    print("1. Adicionar item")
    print("2. Remover item")
    print("3. Listar itens")
    print("4. Limpar lista")
    print("5. Sair")
    opcao = input("Escolha uma opção: ")

    if opcao == "1":
        item = input("Nome do item: ").strip()
        if not item:
            print("Item inválido.")
            continue
        lista.append(item)
        print(f"'{item}' adicionado.")

    elif opcao == "2":
        if not lista:
            print("Lista vazia.")
            continue

        item = input("Nome do item para remover: ").strip()
        if item in lista:
            lista.remove(item)
            print(f"'{item}' removido.")
        else:
            print("Item não encontrado.")

    elif opcao == "3":
        if not lista:
            print("Lista vazia.")
        else:
            print("Itens da lista:")
            for indice, item in enumerate(lista, start=1):
                print(f"{indice}. {item}")

    elif opcao == "4":
        lista.clear()
        print("Lista limpa.")

    elif opcao == "5":
        print("Até a próxima compra!")
        break

    else:
        print("Opção inválida.")
```
