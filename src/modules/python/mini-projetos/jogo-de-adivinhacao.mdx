# Jogo de adivinhação

## Objetivo
Crie um jogo que sorteia um número e dá dicas ao jogador.

## Checklist de autoavaliação
- [ ] O programa aceita entradas do usuário corretamente.
- [ ] As funções principais estão organizadas por responsabilidade.
- [ ] A saída final é legível e útil.
- [ ] Os erros de entrada são tratados com mensagens claras.

## Dicas
- Use random.randint para gerar um número.
- Compare a tentativa do jogador com o valor sorteado.
- Acumule tentativas e termine quando o jogador acertar.
