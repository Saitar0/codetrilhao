# E-mail corporativo e slug

## Contexto
Uma empresa de tecnologia precisa padronizar cadastro de colaboradores e artigos do blog. O time de RH quer criar e-mails corporativos no padrão `nome.sobrenome@empresa.com`, enquanto o time de marketing precisa converter títulos para slugs de URL para campanhas, páginas e SEO.

## O que você vai construir
Um programa que recebe o nome completo de um funcionário e o título de um artigo, limpa o texto, remove acentos e gera duas saídas: o e-mail corporativo e o slug da URL.

Exemplo de execução real:

```text
Nome do funcionário:  María José da Silva 
Título do artigo: Aprenda Python Rápido!
Email corporativo: maria.jose@empresa.com
Slug: aprenda-python-rapido
```

## Requisitos
1. Ler o nome completo do funcionário.
2. Remover espaços duplicados e acentos do nome.
3. Normalizar o texto para minúsculas.
4. Criar o e-mail no formato `nome.sobrenome@empresa.com`.
5. Ler um título de artigo.
6. Transformar texto em slug: minúsculas, sem acentos, sem pontuação e com hífens entre palavras.
7. Tratar nomes compostos e textos com múltiplos espaços.

## Critérios de aceite
- [ ] O nome do funcionário é limpo e normalizado antes do e-mail.
- [ ] O programa remove acentos corretamente.
- [ ] O e-mail usa o padrão da empresa e não deixa espaços ou caracteres inválidos.
- [ ] O slug abrevia o texto para um padrão legível de URL.
- [ ] O código trata nomes compostos e títulos com pontuação.

## Histórias de usuário
- Como RH, quero gerar e-mails corporativos sem depender de digitação manual.
- Como marketing, quero criar slugs automáticos para artigos e campanhas.
- Como analista, quero padronizar textos para evitar inconsistências em dados, relatórios e URLs.

## Arquitetura sugerida
- `normalizar_texto(texto)` para remover acentos, espaços duplicados e pontuação.
- `gerar_email(nome_completo, dominio)` para produzir o formato de e-mail da empresa.
- `gerar_slug(titulo)` para transformar texto em URL amigável.
- `main()` para ler entradas, chamar as funções e imprimir os resultados.

## Casos de teste de aceitação
- Nome: `José da Silva` → e-mail `jose.da@empresa.com` ou `jose.silva@empresa.com` dependendo do padrão da empresa.
- Nome: `  Ana   Maria  Costa  ` → espaços duplicados removidos.
- Título: `Aprenda Python Rápido!` → slug `aprenda-python-rapido`.
- Título: `Como usar o Python 3.11?` → slug `como-usar-o-python-311`.
- Nome com acentos: `Marta Ísis` → texto sem acentos antes do e-mail.

## Riscos
- Acentos e caracteres especiais podem quebrar a padronização e gerar e-mails inválidos.
- Não normalizar espaços duplicados cria nomes inconsistentes em cadastros.
- Usar para slug caracteres não esperados pode produzir URLs quebradas e pouco amigáveis.
- Não remover pontuação do título gera slugs confusos em SEO e links.

```python
import unicodedata


def remover_acentos(texto):
    texto = unicodedata.normalize("NFKD", texto)
    return texto.encode("ascii", "ignore").decode("ascii")


def limpar_nome(nome):
    nome = remover_acentos(nome).strip()
    nome = " ".join(nome.split())
    return nome.lower()


def gerar_email(nome_completo, dominio="empresa.com"):
    partes = limpar_nome(nome_completo).split()
    if len(partes) >= 2:
        return f"{partes[0]}.{partes[-1]}@{dominio}"
    return f"{partes[0]}@{dominio}"


def gerar_slug(titulo):
    texto = remover_acentos(titulo).lower()
    texto = "".join(car if car.isalnum() or car.isspace() else " " for car in texto)
    texto = " ".join(texto.split())
    return texto.replace(" ", "-")


nome = input("Nome do funcionário: ")
titulo = input("Título do artigo: ")

print(f"Email corporativo: {gerar_email(nome)}")
print(f"Slug: {gerar_slug(titulo)}")
```
