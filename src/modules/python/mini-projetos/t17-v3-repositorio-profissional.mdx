## Repositório profissional

## Contexto

Um cliente pediu um microserviço que valida CPFs e gera relatórios simples. Você entregará um repositório com código, testes e instruções de uso.

## O que você vai construir

Um repositório organizado com código de validação, testes e scripts de manutenção. Abaixo há um exemplo ilustrativo da saída de um commit (simulada).

## Requisitos

1. Implementar `validator/cpf.py` exportando `valida_cpf(cpf: str) -> bool`.
2. Fornecer uma suíte de testes em `tests/` que cubra casos normais e borda.
3. Incluir `README.md` com instruções de setup e execução de testes.

## Critérios de aceite

- [ ] `validator/cpf.py` existe e expõe `valida_cpf`.
- [ ] Há pelo menos 8 testes cobrindo regras principais e bordas.
- [ ] O README descreve como criar venv e rodar `pytest`.

### Exemplo de execução ilustrativo (saída simulada)

```bash
[master] conteudo(python): t17 mini projetos de testes e git
 3 files changed, 123 insertions(+), 10 deletions(-)
```

### Histórias de usuário
1. Como usuário, quero validar um CPF e receber True/False.
2. Como integrador, quero executar a suíte de testes localmente com `pytest`.
3. Como revisor, quero commits pequenos e mensagens que expliquem o porquê das mudanças.

### Arquitetura sugerida
- `validator/` - funções de validação (limpeza, dígitos, regras)
- `tests/` - testes unitários e de integração (pytest)
- `scripts/` - scripts de manutenção (ex.: gerar relatório)
- `README.md` com instruções de setup e comandos

### Casos de teste de aceitação
- Validar CPFs válidos conhecidos → True
- CPFs com máscara e espaços → True/False conforme conteúdo
- Sequências repetidas → False
- Arquivo CSV com 100 CPFs → produzir relatório com contagem válidos/invalidos

### Riscos
- Regras de validação mudam entre países/locais; documentar suposições.
- Dependência de bibliotecas externas pode quebrar o ambiente; prefira stdlib.

## Guia de entrega ao cliente (checklist)

- [ ] README com setup e `pytest`
- [ ] Commits pequenos e atômicos
- [ ] Tests cobrem regras principais
