Contexto: validar CPF é tarefa comum em sistemas brasileiros. O foco aqui é projetar conjuntos de testes (unitários e de aceitação) que cubram regras e casos especiais.

## Guia (marcos — sem código pronto)

1. Limpeza e normalização
   - Separar dígitos, remover máscara e espaços.
   - Casos de teste: CPF com pontos/traços, CPF com espaços, string vazia, `None` (se for caso de entrada), CPF com letras.

2. Rejeição de sequências repetidas
   - Sequências como `111.111.111-11` são inválidas.
   - Casos: todas as mesmas casas, variações com máscara, comprimento errado.

3. Cálculo dos dígitos verificadores
   - Implementar multiplicadores decrescentes e regras `r < 2 -> 0` else `11 - r`.
   - Casos: CPF válido conhecido, CPF com dígito errado, base correta mas último dígito trocado.

4. Integração e comportamento em massa
   - Testar uma lista de CPFs, medir taxa de rejeição.
   - Casos: lista com 1000 CPFs (simulados), lista vazia.

```python
# scripts/tmp-mini-projects/t17_v2_solution.py
import re

def limpa_cpf(cpf: str) -> str:
	return re.sub(r"\D", "", cpf)

def sequencia_repetida(cpf: str) -> bool:
	return cpf == cpf[0] * len(cpf)

def calcular_digito(cpf: str, multiplicadores) -> int:
	s = sum(int(d) * m for d, m in zip(cpf, multiplicadores))
	r = s % 11
	return 0 if r < 2 else 11 - r

def valida_cpf(cpf: str) -> bool:
	c = limpa_cpf(cpf)
	if len(c) != 11 or not c.isdigit():
		return False
	if sequencia_repetida(c):
		return False
	base = c[:9]
	d1 = calcular_digito(base, range(10, 1, -1))
	d2 = calcular_digito(base + str(d1), range(11, 1, -1))
	return c == base + str(d1) + str(d2)

if __name__ == '__main__':
	exemplos = [
		'529.982.247-25',
		'111.111.111-11',
		'123.456.789-09',
		'935.411.347-80',
	]
	for e in exemplos:
		print(e, '->', valida_cpf(e))
```
