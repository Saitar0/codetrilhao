# Estoque e vendas

## Contexto
Uma loja pequena precisa controlar o que entra e sai do estoque sem perder o controle dos produtos e do lucro. O desafio não é só registrar vendas; é manter um fluxo seguro em que cada venda reduz o estoque, cada entrada aumenta a quantidade disponível e os alertas de mínimo ajudam a decidir novos pedidos.

## O que você vai construir
Um sistema de controle de estoque e vendas em terminal. O programa deve permitir cadastrar produtos, registrar entradas e saídas, consultar produto por nome ou código, verificar estoque mínimo e gerar relatório de vendas com ganho líquido.

## Requisitos
1. Menu em loop com opções de cadastro, venda, entrada, consulta e relatório.
2. Classes para `Produto`, `MovimentoEstoque` e `Loja` ou `ControleEstoque`.
3. Persistência em SQLite com tabelas para `produtos` e `movimentos`.
4. Tratamento de erros para quantidade inválida, código inexistente e preço negativo.
5. Alertas de estoque mínimo por produto.
6. Cálculo de lucro por venda, considerando preço de compra e preço de venda.
7. Relatório com produtos mais vendidos, itens em baixa e faturamento total.
8. Organização em módulos para menu, regras e banco de dados.
9. README com instruções, exemplo de uso e estrutura do projeto.
10. Testes automatizados para estoque, preços e regras de venda.

## Critérios de aceite
- [ ] O sistema cadastra produtos com nome, preço de compra, preço de venda e quantidade inicial.
- [ ] Vendas só podem ocorrer com estoque suficiente.
- [ ] O relatório mostra itens com quantidade mínima e produtos em destaque.
- [ ] O usuário consegue pesquisar produto por código ou nome.
- [ ] Há validação de preço, quantidade e código inexistente.
- [ ] O banco SQLite registra entradas e saídas em momentos distintos.
- [ ] Há testes para casos de ausência de estoque e valor inválido.

## Histórias de usuário
1. Como dono da loja, quero cadastrar produtos para controlar o inventário.
2. Como vendedor, quero registrar uma venda sem que o estoque fique negativo.
3. Como gestor, quero ver quais itens estão abaixo do mínimo para comprar novamente.
4. Como analista, quero calcular lucro por venda e faturamento total do período.

## Modelo de dados
Use classes para representar produtos e movimentações. O banco deve guardar os dados de forma organizada.

```python
from dataclasses import dataclass

@dataclass
class Produto:
    nome: str
    preco_compra: float
    preco_venda: float
    estoque_atual: int
    estoque_minimo: int
```

```sql
CREATE TABLE IF NOT EXISTS produtos (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    nome TEXT NOT NULL UNIQUE,
    preco_compra REAL NOT NULL,
    preco_venda REAL NOT NULL,
    estoque_atual INTEGER NOT NULL,
    estoque_minimo INTEGER NOT NULL
);

CREATE TABLE IF NOT EXISTS movimentos (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    produto_id INTEGER NOT NULL,
    tipo TEXT NOT NULL CHECK(tipo IN ('entrada', 'saida')),
    quantidade INTEGER NOT NULL,
    valor_total REAL NOT NULL,
    data TEXT NOT NULL,
    FOREIGN KEY (produto_id) REFERENCES produtos(id)
);
```

## Guia
### Como começar
- Defina uma regra central: a venda só deve ser validada quando o estoque for suficiente.
- Armazene sempre a composição de preços e quantidade em `movimentos` para provar cada operação.
- Use uma função `lucro_total()` e uma função `faturamento_total()` em vez de repetir cálculos.

### Fluxo recomendado
- Cadastre 3 a 5 produtos iniciais com nome, preço e estoque mínimo.
- Registre uma entrada para cada produto.
- Faça uma venda e verifique se o saldo financeiro e o estoque foram atualizados.
- Gere um relatório com os itens mais vendidos e os produtos em alerta.

### Dicas práticas
- Evite armazenar o lucro final como valor duplicado em duas tabelas; calcule com base nos movimentos.
- Use `CHECK` em SQL para garantir tipos válidos.
- Separe leitura de banco e atualização de estoque em funções diferentes.

class Produto:
    def __init__(self, nome, preco_compra, preco_venda, estoque_atual, estoque_minimo):
        self.nome = nome
        self.preco_compra = preco_compra
        self.preco_venda = preco_venda
        self.estoque_atual = estoque_atual
        self.estoque_minimo = estoque_minimo

    def lucro_por_unidade(self):
        return self.preco_venda - self.preco_compra
