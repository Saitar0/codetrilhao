# Conversor de moedas fixo

## Contexto
Você foi pedido para preparar uma ferramenta simples de conversão para um cliente que quer saber quanto um valor em reais vale em outras moedas. A regra é usar cotações fixas definidas no topo do programa.

## O que você vai construir
Um conversor de reais para dólar, euro e libra. O programa lê um valor, converte com taxas fixas e mostra o resultado em cada moeda com duas casas decimais.

Exemplo de execução:

```text
Digite o valor em reais: 250
Você digitou: R$ 250.00

Dólar: US$ 48.08
Euro: € 40.98
Libra: £ 34.72
```

## Requisitos
1. Definir as cotações em variáveis no topo do programa.
2. Ler o valor em reais com `input()`.
3. Converter para dólar, euro e libra.
4. Mostrar cada valor com duas casas decimais.
5. Tratar entrada inválida ou valor negativo.

## Critérios de aceite
- [ ] As cotações ficam fora da lógica principal.
- [ ] O programa converte corretamente para as 3 moedas.
- [ ] A saída usa 2 casas decimais.
- [ ] Entrada vazia ou texto inválido gera mensagem clara.
- [ ] Valores negativos ou zero são tratados com regra definida.

## Guia
### Marco 1: definir a regra de negócio
- Decida as cotações fixas no início do programa.
- Mantenha-as em variáveis separadas para facilitar a leitura.
- Registre a regra que o programa vai seguir: um valor em reais dividido pela cotação.

### Marco 2: receber e validar o valor
- Use `float(input(...))` para converter a entrada.
- Se o valor for negativo, mostre uma mensagem de aviso.
- Se a entrada for vazia ou não numérica, avise o usuário.

### Marco 3: calcular as conversões
- Calcule cada moeda com operação simples.
- Arredonde para duas casas decimais no momento da impressão.
- Use `print()` para separar os resultados.

### Marco 4: testar casos especiais
- Valor zero deve mostrar 0,00 nas 3 moedas.
- Valor negativo deve ser rejeitado.
- Entrada com texto deve gerar uma mensagem amigável.

### Marco 5: revisar a saída
- A frase inicial deve explicar o valor que foi lido.
- A resposta final precisa ficar clara e legível no terminal.

Conversores de moeda aparecem em ferramentas financeiras, dashboards pessoais, aplicativos de viagem e sistemas de controle de orçamento. Mesmo em versões simples, eles precisam deixar claro a regra da cotação e o arredondamento.

<details>
  <summary>Solução de referência</summary>

```python
valor_reais = float(input("Digite o valor em reais: "))

cotacao_dolar = 5.20
cotacao_euro = 6.10
cotacao_libra = 7.20

if valor_reais < 0:
    print("Digite um valor maior ou igual a zero.")
else:
    dolar = valor_reais / cotacao_dolar
    euro = valor_reais / cotacao_euro
    libra = valor_reais / cotacao_libra

    print(f"Você digitou: R$ {valor_reais:.2f}")
    print(f"Dólar: US$ {dolar:.2f}")
    print(f"Euro: € {euro:.2f}")
    print(f"Libra: £ {libra:.2f}")
```
