# Adivinhe o número

## Contexto
Você foi contratado para criar um mini jogo para uma plataforma de aprendizagem. O objetivo é tornar a lógica de adivinhação divertida, mas também clara: o computador escolhe um número, o jogador tenta várias vezes e recebe dicas sobre se o valor é maior ou menor.

## O que você vai construir
Um jogo em que o computador sorteia um número entre 1 e 100, o usuário tenta adivinhar e recebe feedback até acertar ou atingir o limite de tentativas. A ideia é praticar `while`, condição de parada e contador de tentativas em um cenário de decisão simples.

Exemplo de execução real:

```text
Adivinhe o número (1 a 100)
Tentativa 1: 50
O número é menor.
Tentativa 2: 25
O número é maior.
Tentativa 3: 35
Parabéns! Você acertou em 3 tentativas.
```

## Requisitos
1. Sortear um número aleatório entre 1 e 100.
2. Permitir que o jogador insira tentativas até acertar.
3. Dar dicas "maior" ou "menor" conforme a comparação.
4. Registrar o número de tentativas.
5. Encerrar corretamente quando o jogador acertar ou quando o limite for atingido.

## Critérios de aceite
- [ ] O número sorteado fica sempre dentro do intervalo pedido.
- [ ] A cada tentativa, o programa compara o chute com o valor sorteado.
- [ ] O programa informa se o número é maior ou menor.
- [ ] O contador de tentativas aumenta em cada chute válido.
- [ ] O jogo termina ao acertar ou ao esgotar as tentativas.
- [ ] O aluno consegue repetir uma partida sem duplicar o código.

## Guia
### Marcos do projeto
1. Sorteie um número com `random.randint(1, 100)`.
2. Crie uma variável para o limite de tentativas e outra para controlar as tentativas do jogador.
3. Use `while` para manter o jogo rodando até o jogador acertar ou até o limite ser alcançado.
4. Compare cada tentativa com o valor sorteado e imprima a dica correta.
5. Ao final, mostre se o jogador venceu ou perdeu e ofereça a opção de jogar novamente.

### Dicas
- Mantenha a condição de parada visível: o jogo pode continuar enquanto `tentativas < limite` e `acertou` for `False`.
- Use `if` para testar igualdade, maior e menor; essa separação deixa o código mais claro.
- Quando o usuário errar e o limite não foi alcançado, o programa deve pedir outra tentativa.

<Callout type="importante" title="Regra central">
O loop de adivinhação precisa controlar duas coisas ao mesmo tempo: a tentativa atual e a condição de parada. Sem isso, você pode cair em um laço que nunca termina ou em um programa que não registra o progresso do jogador.
</Callout>

```python
import random

numero_sorteado = random.randint(1, 100)
limite_tentativas = 7
contador = 0
acertou = False

while contador < limite_tentativas and not acertou:
    tentativa = int(input(f"Tentativa {contador + 1}: "))
    contador += 1

    if tentativa == numero_sorteado:
        acertou = True
        print(f"Parabéns! Você acertou em {contador} tentativas.")
    elif tentativa < numero_sorteado:
        print("O número é maior.")
    else:
        print("O número é menor.")

if not acertou:
    print(f"Você perdeu! O número era {numero_sorteado}.")
```
