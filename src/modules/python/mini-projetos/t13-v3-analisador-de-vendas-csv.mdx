# Analisador de vendas a partir de CSV

## Contexto
Uma loja envia uma planilha de vendas com alguns problemas: campos vazios, valores sem padrão e linhas inconsistentes. O time precisa transformar esse arquivo em um relatório confiável para saber quanto foi vendido, por produto e por vendedor.

## O que você vai construir
Um analisador que lê um CSV em memória, ignora registros inválidos, calcula o faturamento total e mostra um resumo por vendedor e produto. O objetivo é simular um fluxo real de limpeza e extração de dados, sem depender de planilhas manuais.

Exemplo de execução real:

```text
=== Relatório de vendas ===
Total geral: R$ 2.275,00
Faturamento por vendedor:
Ana: R$ 1.325,00
Bruno: R$ 150,00
Carla: R$ 800,00
Produto mais vendido: Teclado
```

## Requisitos
1. Receber um CSV em formato de texto com linha e coluna separadas por `;`.
2. Ler cada linha com `csv.DictReader` ou `csv.reader`.
3. Ignorar registros com campos vazios ou valores inválidos.
4. Calcular o valor total das vendas válidas.
5. Agrupar faturamento por vendedor e produto.
6. Exibir um resumo final de forma legível.

## Critérios de aceite
- [ ] O programa consegue ler um CSV com `;` como separador.
- [ ] Linhas com dados vazios ou incompletos são ignoradas.
- [ ] O total geral considera somente registros válidos.
- [ ] O resumo por vendedor mostra valores separados corretamente.
- [ ] O aluno consegue explicar por que a limpeza de dados é parte do trabalho com CSV.
- [ ] O relatório final é legível para um cliente ou gestor.
- [ ] O código separa leitura, limpeza e cálculo em funções ou etapas claras.

## Histórias de usuário
- Como gerente, quero ver o faturamento total para decidir se a campanha foi boa.
- Como analista, quero saber quais vendedores mais venderam no período.
- Como suporte, quero identificar registros inválidos sem derrubar o restante da análise.
- Como cliente, quero receber um relatório simples, sem precisar abrir a planilha manualmente.

## Arquitetura sugerida
- `ler_csv_texto(texto)` para transformar a entrada em linhas processáveis.
- `limpar_venda(linha)` para validar campos e remover entradas incompletas.
- `agrupar_por_vendedor(vendas)` para somar faturamento por pessoa.
- `agrupar_por_produto(vendas)` para identificar produto mais vendido.
- `gerar_relatorio(vendas)` para mostrar o resumo final em texto.

## Casos de teste de aceitação
- CSV com linha vazia deve ser ignorada.
- Vendedor sem nome deve ser descartado.
- Produto sem valor ou quantidade inválida deve ser rejeitado.
- Arquivo misto com vendas válidas e inválidas deve processar apenas o que dá para calcular.
- Resumo final deve refletir corretamente o total e a ordem do ranking.

## Riscos
- Aceitar valores vazios sem validar antes do cálculo gera resultados enganosos.
- Misturar regras de parsing com regras de negócio deixa o código difícil de depurar.
- Não separar limpeza de dados reduz a confiabilidade do relatório final.
- Ignorar o caso de linhas inconsistentes faz o programa parecer correto sem estar.

- `csv.DictReader` ajuda a acessar cada coluna por nome, como `"produto"` e `"valor"`.

```python
import csv
import io

csv_texto = '''produto;vendedor;valor;quantidade
Teclado;Ana;250;2
Mouse;Bruno;150;1
Monitor;;600;
Teclado;Ana;275;3
Webcam;Carla;400;2
'''


def linha_valida(linha):
    return (
        linha.get("produto")
        and linha.get("vendedor")
        and linha.get("valor")
        and linha.get("quantidade")
    )


def parse_float(valor):
    try:
        return float(valor.replace(",", "."))
    except (AttributeError, ValueError):
        return None


leitor = csv.DictReader(io.StringIO(csv_texto), delimiter=';')
vendas = []
for linha in leitor:
    if not linha_valida(linha):
        continue

    valor = parse_float(linha["valor"])
    quantidade = parse_float(linha["quantidade"])
    if valor is None or quantidade is None:
        continue

    vendas.append({
        "produto": linha["produto"].strip(),
        "vendedor": linha["vendedor"].strip(),
        "valor": valor,
        "quantidade": quantidade,
    })

faturamento_total = sum(venda["valor"] * venda["quantidade"] for venda in vendas)
por_vendedor = {}
for venda in vendas:
    vendedor = venda["vendedor"]
    por_vendedor[vendedor] = por_vendedor.get(vendedor, 0) + venda["valor"] * venda["quantidade"]

por_produto = {}
for venda in vendas:
    produto = venda["produto"]
    por_produto[produto] = por_produto.get(produto, 0) + venda["valor"] * venda["quantidade"]

produto_mais_vendido = max(por_produto, key=por_produto.get)

print("=== Relatório de vendas ===")
print(f"Total geral: R$ {faturamento_total:,.2f}".replace(",", "X").replace(".", ",").replace("X", "."))
print("Faturamento por vendedor:")
for vendedor, valor in sorted(por_vendedor.items()):
    print(f"{vendedor}: R$ {valor:,.2f}".replace(",", "X").replace(".", ",").replace("X", "."))
print(f"Produto mais vendido: {produto_mais_vendido}")
```
