# Analisador de notas da turma

## Contexto
Você precisa interpretar um conjunto de notas e resumir o desempenho da turma em apenas alguns cálculos úteis.

## O que você vai construir
Um pequeno analisador estatístico que calcula média, mediana, menor e maior nota.

## Requisitos
- Receber uma lista de notas.
- Calcular a média.
- Encontrar a maior e menor nota.
- Exibir a mediana final.

## Critérios de aceite
- Os cálculos estão corretos para números positivos.
- A lógica é clara e reutilizável.
- A saída final ajuda a interpretar o desempenho.

## Guia
1. Armazene as notas em uma lista.
2. Faça operações sobre a lista com funções auxiliares.
3. Ordene a lista para calcular a mediana.
4. Exiba todos os resultados em uma mensagem final.

print(notas)`} />

## Desafio extra
Adicione uma opção para mostrar a quantidade de alunos acima da média e a distribuição por faixa de notas.

```python
notas = [7, 8, 9, 10, 6, 5]
notas_ordenadas = sorted(notas)
media = sum(notas) / len(notas)
mediana = notas_ordenadas[len(notas_ordenadas) // 2]

print(f"Média: {media:.2f}")
print(f"Maior: {max(notas)}")
print(f"Menor: {min(notas)}")
print(f"Mediana: {mediana}")
```
