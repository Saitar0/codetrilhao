# Analisador de notas da turma

## Contexto
Você precisa interpretar um conjunto de notas e tecer um resumo útil para a turma. Em vez de contar tudo manualmente, você quer usar estruturas prontas e operações que deixam a análise mais curta, mais legível e mais confiavel. Isso também ajuda a preparar o aluno para relatórios reais em educação, RH e operações.

## O que você vai construir
Um pequeno analisador que recebe alunos e notas, calcula a media da turma, mostra os aprovados, identifica a maior e menor nota, calcula a mediana e ordena o ranking final. A lógica deve usar comprehensions e `sorted(key=...)` sempre que a regra for simples.

Exemplo de execução real:

```text
=== Analisador de notas da turma ===
Media da turma: 7.93
Aprovados: Ana, Caio, Dani, Ema, Gabi
Maior nota: 9.8
Menor nota: 5.7
Mediana: 8.50
Ranking:
1. Gabi - 9.8
2. Caio - 9.2
3. Ema - 8.9
4. Ana - 8.5
5. Dani - 7.4
6. Beto - 6.0
7. Leo - 5.7
Acima da media: Ana, Caio, Ema, Gabi
```

## Requisitos
1. Receber uma lista de alunos com nome e nota.
2. Extrair todas as notas em uma estrutura simples usando comprehension.
3. Calcular a media da turma com `sum` e `len`.
4. Ordenar os alunos com `sorted` e `key=lambda ...` para montar o ranking.
5. Mostrar aprovados, maior nota, menor nota e alunos acima da media.
6. Tratar casos especiais como turma vazia, notas iguais e lista com quantidade par de elementos.

## Critérios de aceite
- [ ] A lista de alunos é tratada como estrutura de dados organizada.
- [ ] A media da turma é calculada corretamente para qualquer lista de notas.
- [ ] A mediana considera o caso de quantidade par e ímpar de elementos.
- [ ] O ranking está ordenado pela nota em ordem decrescente.
- [ ] A saída mostra aprovados e alunos acima da media com nomes claros.
- [ ] O aluno consegue apontar partes do código que usam comprehensions e `sorted` com `key` de forma natural.

## Guia
### Marcos do projeto
1. Estruture a lista de alunos em dicionarios com `nome` e `nota`.
2. Extraia as notas em outra lista para calcular media, maior nota e menor nota.
3. Ordene a lista de alunos por nota usando `sorted(alunos, key=lambda aluno: aluno["nota"], reverse=True)`.
4. Use comprehensions para criar listas de aprovados e alunos acima da media.
5. Revise o caso de turma vazia e o cálculo da mediana antes de fechar o programa.

### Regras e casos especiais
- Se a turma estiver vazia, a media deve ser `0.0` ou uma mensagem clara de ausência de dados.
- Se a lista de notas tiver quantidade par, a mediana é a media das duas notas centrais.
- Se a lista tiver quantidade ímpar, a mediana é o valor central exato.
- Caso haja empate em nota, a ordem final pode manter a entrada original ou usar ordenação secundaria por nome.
- O aluno pode usar `any` ou `all` para ajustar a lógica de aprovação, mas não é requisito obrigatório.

### Dicas
- Para media, pense em `sum(notas) / len(notas)` e tenha uma regra de proteção para lista vazia.
- `sorted` com `key` funciona bem quando você quer ordenar objetos por um campo interno, como `nota`.
- Comprehensions tornam a criação de listas de aprovados e acima da media mais simples e menos repetitiva.
- A saída do ranking fica mais clara se você usar `enumerate` para numerar as posições.

```python
# -*- coding: utf-8 -*-

alunos = [
    {"nome": "Ana", "nota": 8.5},
    {"nome": "Beto", "nota": 6.0},
    {"nome": "Caio", "nota": 9.2},
    {"nome": "Dani", "nota": 7.4},
    {"nome": "Ema", "nota": 8.9},
    {"nome": "Gabi", "nota": 9.8},
    {"nome": "Leo", "nota": 5.7},
]

notas = [aluno["nota"] for aluno in alunos]
notas_ordenadas = sorted(notas)
media = sum(notas) / len(notas) if notas else 0.0
mediana = (notas_ordenadas[len(notas_ordenadas) // 2 - 1] + notas_ordenadas[len(notas_ordenadas) // 2]) / 2 if len(notas_ordenadas) % 2 == 0 else notas_ordenadas[len(notas_ordenadas) // 2]
aprovados = [aluno["nome"] for aluno in alunos if aluno["nota"] >= 7]
acima_media = [aluno["nome"] for aluno in alunos if aluno["nota"] > media]
classificacao = sorted(alunos, key=lambda aluno: aluno["nota"], reverse=True)

print("=== Analisador de notas da turma ===")
print(f"Media da turma: {media:.2f}")
print(f"Aprovados: {', '.join(aprovados)}")
print(f"Maior nota: {max(notas)}")
print(f"Menor nota: {min(notas)}")
print(f"Mediana: {mediana:.2f}")
print("Ranking:")
for pos, aluno in enumerate(classificacao, start=1):
    print(f"{pos}. {aluno['nome']} - {aluno['nota']}")
print(f"Acima da media: {', '.join(acima_media)}")
```
