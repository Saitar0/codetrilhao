# Algoritmos: busca e ordenação

Você já precisou localizar um tên do cadastro, organizar uma lista de preços ou decidir quem entra primeiro em uma fila? Problemas dessa natureza aparecem em sistemas simples e complexos. A boa notícia é que a solução começa sempre com a mesma ideia: descrever a entrada, o processamento e a saída antes de codar.

<Callout type="importante" title="O que você vai aprender">
  - Como decompor um problema em entrada, processamento e saída.
  - Como implementar busca linear e busca binária.
  - Como ordenar listas com algoritmos didáticos e com `sorted`.
  - Como pensar em custo de execução usando noções de $O(1)$, $O(log n)$ e $O(n^2)$.
</Callout>

## Decompondo o problema

Antes de escrever código, vale transformar o problema em passos claros. Em vez de pensar só em “como fazer?”, você pergunta: qual é a entrada? o que deve mudar? qual é a resposta final? Esse tipo de descrição ajuda muito na hora de depurar.

Em pseudocódigo, a lógica de uma busca costuma ser:

```text
entrada: lista e alvo
para cada elemento:
    comparar com o alvo
    se encontrar -> retornar a posição
fim
se não encontrar -> retornar -1
```

A ordem da lista também importa. A busca binária só faz sentido em uma lista já organizada.

<CodeBlock title="processar_pedido.py" code={`def processar_pedido(precos):
    precos_ordenados = sorted(precos)
    return precos_ordenados[0]

print(processar_pedido([45, 10, 28, 19]))
`} />

Saída:

```text
10
```

Essa função pega a entrada, ordena os valores e devolve o menor. É um exemplo simples de como organizar dados antes de tomar uma decisão.

<Glossario termo="Pré-condição" definition="Requisito que precisa ser verdadeiro antes de usar um algoritmo; por exemplo, lista ordenada para busca binária." />
<Glossario termo="Busca linear" definition="Percorrer a lista item por item até encontrar o alvo ou chegar ao fim." />
<Glossario termo="Custo de algoritmo" definition="Medida de como o tempo e o espaço crescem conforme a entrada aumenta." />

## Busca linear

A busca linear é a estratégia mais direta. Você percorre a lista do início ao fim e compara cada valor com o alvo. Se encontrar, retorna a posição; se não aparecer, devolve `-1`.

Ela funciona com qualquer lista, ordenada ou não, e por isso é fácil de entender. O custo cresce proporcionalmente ao tamanho da lista: no pior caso, você compara até $n$ elementos.

<CodeBlock title="busca_linear.py" code={`def busca_linear(lista, alvo):
    for indice, valor in enumerate(lista):
        if valor == alvo:
            return indice
    return -1

print(busca_linear([9, 5, 3, 8, 12], 8))
print(busca_linear([9, 5, 3, 8, 12], 7))
`} />

Saída:

```text
3
-1
```

Quando você precisa de algo rápido e a lista é pequena, busca linear é uma escolha simples e previsível.

## Busca binária

A busca binária reduz o espaço de busca a cada passo. Ela só funciona quando a lista está ordenada. O algoritmo calcula o meio, compara com o alvo e descarta a metade que não pode conter a resposta.

Esse tipo de estratégia tem custo $O(log n)$, porque a busca reduz pela metade a cada iteração. Em listas grandes, isso muda bastante o desempenho.

<CodeBlock title="busca_binaria.py" code={`def busca_binaria(lista, alvo):
    inicio, fim = 0, len(lista) - 1
    while inicio <= fim:
        meio = (inicio + fim) // 2
        if lista[meio] == alvo:
            return meio
        if lista[meio] < alvo:
            inicio = meio + 1
        else:
            fim = meio - 1
    return -1

numeros = [2, 4, 6, 8, 10, 12, 14]
print(busca_binaria(numeros, 10))
print(busca_binaria(numeros, 11))
`} />

Saída:

```text
4
-1
```

## Ordenação didática

Ordenar dados é outro problema clássico. O bubble sort compara elementos vizinhos e troca a ordem quando necessário. Ele é fácil de entender, mas cresce em $O(n^2)$ e fica lento em listas grandes.

<CodeBlock title="bubble_sort.py" code={`def bubble_sort(lista):
    n = len(lista)
    for i in range(n):
        for j in range(0, n - i - 1):
            if lista[j] > lista[j + 1]:
                lista[j], lista[j + 1] = lista[j + 1], lista[j]
    return lista

print(bubble_sort([5, 1, 4, 2, 8]))
`} />

Saída:

```text
[1, 2, 4, 5, 8]
```

<StepThrough>
  <div>
    <p><strong>Etapa 1:</strong> a lista começa em [5, 1, 4, 2]. O maior valor vai “subindo” passo a passo.</p>
  </div>
  <div>
    <p><strong>Etapa 2:</strong> o algoritmo compara pares vizinhos e troca quando a ordem está errada.</p>
  </div>
  <div>
    <p><strong>Etapa 3:</strong> depois de várias passadas, a lista fica ordenada: [1, 2, 4, 5].</p>
  </div>
</StepThrough>

No dia a dia, você geralmente usa `sorted` ou `list.sort()`. Esses métodos já resolvem a maioria dos casos de forma eficiente.

<CodeBlock title="sorted_simples.py" code={`notas = [7, 3, 9, 1, 6]
print(sorted(notas))
print(sorted(notas, reverse=True))
`} />

Saída:

```text
[1, 3, 6, 7, 9]
[9, 7, 6, 3, 1]
```

<Glossario termo="FIFO" definition="First In, First Out: a primeira informação a entrar é a primeira a sair, como em uma fila." />

## Pilhas e filas

Pilha e fila são estruturas úteis em vários problemas. Em uma pilha, o último elemento a entrar sai primeiro. Em uma fila, o primeiro a entrar sai primeiro.

<CodeBlock title="pilha_e_fila.py" code={`pilha = [10, 20]
pilha.append(30)
print(pilha.pop())

from collections import deque
fila = deque(['Ana', 'Bia'])
fila.append('Caio')
print(fila.popleft())
`} />

Saída:

```text
30
Ana
```

Essas estruturas são úteis em filas de atendimento, processamento de eventos e até em problemas mais complexos de análise.

## No mercado de trabalho

Em tecnologia, busca e ordenação aparecem em bancos, e-commerces, sistemas de atendimento e relatórios. O importante não é memorizar nomes isolados, mas saber escolher a estratégia certa. A busca linear é simples e robusta; a busca binária é mais eficiente quando a estrutura já está pronta; a ordenação ajuda a preparar dados para análise e decisão.
