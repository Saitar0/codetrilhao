# Comprehensions

Crie listas e dicionários de maneira concisa e expressiva.

<Callout type="importante" title="Objetivo da aula">
  Neste bloco, você vai entender o conceito principal, ver exemplos práticos e testar a lógica em pequenos passos.
</Callout>

<CodeBlock title="exemplo_1.py" code={`quadrados = [n * n for n in range(5)]
print(quadrados)`} />
<CodeBlock title="exemplo_2.py" code={`pares = [n for n in range(10) if n % 2 == 0]
print(pares)`} />
<CodeBlock title="exemplo_3.py" code={`dobros = {n: n * 2 for n in range(3)}
print(dobros)`} />
