# Strings

Você provavelmente já viu textos em todos os lugares: nome de usuário, e-mails, mensagens de erro, endereços e relatórios. Em Python, tudo isso é representado por strings: sequências de caracteres que guardam letras, números, espaços e símbolos. Elas parecem simples, mas são uma das estruturas mais importantes da linguagem porque quase todo programa precisa tratar texto de algum jeito.

Se você já escreveu `"Olá"` ou `"Ana"`, então já usou strings. O próximo passo é entender como navegar dentro desse texto, limpar informações sujas, transformar letras, comparar palavras e formatar saídas para o usuário. Isso é útil em sistemas de cadastro, validação de dados, mensagens de interface e processamento de arquivos.

<Callout type="importante" title="O que você vai aprender">
  - Como criar strings com aspas, escapes e textos em múltiplas linhas.
  - Como acessar partes do texto com índice e fatiamento.
  - Como limpar e transformar texto com métodos como `strip`, `upper` e `replace`.
  - Como buscar, contar e validar informações dentro de uma string.
  - Como formatar saídas com f-strings e lidar com Unicode e acentos.
</Callout>

## 1. Criando, lendo e escapando texto

Uma string é uma sequência de caracteres. Em Python, você pode criá-la com aspas simples, duplas ou triplas. Aspas triplas são úteis quando a mensagem ocupa várias linhas ou quando você quer preservar a formatação do texto.

<CodeBlock title="criando_strings.py" code={`nome = "Maria"
mensagem = 'Olá, mundo!'
texto_longo = """Python é simples,
mas exige atenção."""

print(nome)
print(mensagem)
print(texto_longo)`} />

```text
Maria
Olá, mundo!
Python é simples,
mas exige atenção.
```

Aqui, você vê algo importante: Python trata caracteres especiais e acentos como parte normal da string. Isso é essencial para sistemas em português, em que nomes, cidades, e-mails e textos do cotidiano aparecem com letras acentuadas e símbolos diferentes.

Além disso, strings aceitam sequências especiais com escape. Por exemplo, `\n` significa quebra de linha e `\t` significa tabulação. Isso ajuda a montar mensagens em múltiplas linhas ou com espaçamento controlado.

<CodeBlock title="escapes.py" code={`frase = "Linha 1\nLinha 2\t--\tLinha 3"
print(frase)`} />

```text
Linha 1
Linha 2	--	Linha 3
```

A barra invertida indica que o próximo caractere recebe um significado especial. Esse recurso aparece muito em logs, relatórios, mensagens e geração de texto.

## 2. Indexação, fatiamento e a lógica da posição

Cada caractere em uma string ocupa uma posição. Em Python, a contagem começa em 0. Isso significa que o primeiro caractere está no índice 0, o segundo no índice 1, e assim por diante. Também é possível usar índices negativos: `-1` pega o último caractere, `-2` o penúltimo e assim por diante.

<CodeBlock title="indice_e_fatia.py" code={`texto = "Python"
print(texto[0])
print(texto[2])
print(texto[-1])
print(texto[:3])
print(texto[2:])
print(texto[::-1])`} />

```text
P
t
n
Pyt
thon
nohtyP
```

A sintaxe `texto[inicio:fim:passo]` é chamada de <Glossario termo="fatiamento" definition="Seleção de parte de uma string usando início, fim e passo." />. Essa ideia é muito poderosa porque ela permite pegar e manipular pedaços do texto sem alterar todo o conteúdo.

O slice `[:3]` pega os três primeiros caracteres. O trecho `[2:]` começa no índice 2 e vai até o fim. Já `[::-1]` inverte toda a string, porque o passo é `-1`. Isso é o motivo pelo qual muitas soluções em Python ficam tão curtas e legíveis.

<StepThrough>
  <div>
    <p>Primeiro, você vê a string <strong>"Python"</strong>. A posição 0 é a letra <strong>P</strong>.</p>
  </div>
  <div>
    <p>Depois, o Python pega <strong>texto[:3]</strong>, que significa “do começo até antes do índice 3”. Isso devolve <strong>"Pyt"</strong>.</p>
  </div>
  <div>
    <p>Por fim, com <strong>texto[::-1]</strong>, ele percorre a string ao contrário e imprime <strong>"nohtyP"</strong>. O padrão fica claro: o slice pode ser usado para separar, inverter e explorar sequências.</p>
  </div>
</StepThrough>

## 3. Métodos para limpar, transformar e comparar texto

Strings têm muitos métodos que fazem operações comuns. Isso significa que você não precisa reinventar a lógica para cada tarefa. Em vez de montar passos manuais para remover espaços e trocar letras, Python já oferece ferramentas prontas.

<CodeTabs>
  <div label="Limpeza">
    <CodeBlock title="limpeza.py" code={`nome = "  joão da silva  "
print(nome.strip())
print(nome.upper())
print(nome.title())
print(nome.replace(" ", "-"))`} />
  </div>
  <div label="Busca e comparação">
    <CodeBlock title="busca.py" code={`nome = "Ana"
print(nome.upper())
print(nome.lower())
print(nome.title())
print(nome.startswith('A'))
print(nome.count('a'))`} />
  </div>
</CodeTabs>

```text
joão da silva
  JOÃO DA SILVA  
joão da silva
--joão-da-silva--

ANA
ana
Ana
True
1
```

O primeiro bloco mostra o que os métodos mais usados fazem:

- `strip()` remove espaços no começo e no fim.
- `upper()` converte tudo para maiúsculas.
- `title()` coloca a primeira letra de cada palavra em maiúscula.
- `replace()` troca um texto por outro.

No segundo bloco, você vê mais capacidade de análise. `startswith()` verifica se a string começa com um valor específico; `count()` conta quantas vezes um caractere aparece. Isso é muito útil em validações e relatórios.

Uma parte importante para quem trabalha com texto é a <Glossario termo="imutabilidade" definition="Propriedade de que uma string, depois criada, não pode ser alterada em lugar." />. Quando você faz `texto = texto.replace(" ", "-")`, o Python retorna uma nova string. A string original continua intacta; você precisa guardar o resultado em outra variável ou substituir a própria variável.

## 4. Operações com strings: concatenação, repetição e busca

Strings podem ser somadas e repetidas. Isso é algo que parece simples, mas aparece muito em relatórios, geradores de código, mensagens e ajustes de saída.

<CodeBlock title="operacoes_string.py" code={`texto = "python"
print(texto + "!")
print(texto * 3)
print('py' in texto)
print(len(texto))`} />

```text
python!
pythonpythonpython
True
6
```

A operação `+` concatena texto, enquanto `*` repete a string. O operador `in` verifica se uma parte está contida na string, e `len()` devolve o tamanho dela. Essa combinação é muito útil para validar e montar frases de forma legível.

Também é comum usar `.split()` para separar um texto em partes e `"-".join(...)` para reunir as partes em uma única string. Em outras palavras, `split` divide; `join` junta.

<CodeBlock title="split_join.py" code={`email = "  MARIA.SILVA@Empresa.com  "
limpo = email.strip().lower()
usuario, dominio = limpo.split("@")
print(usuario, dominio)
print(limpo[::-1])`} />

```text
maria.silva empresa.com
moc.aserpme@avlis.airam
```

Esse código mostra um caso realista: limpar espaços, transformar letras para minúsculas e separar usuário e domínio do e-mail. A linha `limpo[::-1]` inverte a string inteira e mostra como o fatiamento pode ser usado para olhar o texto de trás para frente.

## 5. Buscando padrões e tratando texto sujo

Quando você trabalha com textos reais, eles quase nunca chegam perfeitos. Há espaços extras, letras em caixa diferente, nomes com acento e formatos inconsistentes. A boa notícia é que Python oferece vários métodos para resolver isso.

<Playground title="Experimente busca e validação em texto" code={`texto = "  CPF: 123.456.789-09  "
texto_limpo = texto.strip()
print(texto_limpo)
print(texto_limpo.startswith('CPF'))
print(texto_limpo.endswith('09'))
print('123' in texto_limpo)
print('cpf' in texto_limpo.lower())`} />

Além disso, existem verificações úteis para saber se uma string contém só números ou só letras, por exemplo `isdigit()` e `isalpha()`. Isso é útil em formulários, validações de entrada e filtros simples.

<CodeBlock title="validacao_textual.py" code={`senha = "abc123"
print(senha.isdigit())
print(senha.isalpha())
print("123".isdigit())
print("Python".isalpha())`} />

```text
False
False
True
True
```

Esse tipo de verificação é uma etapa importante antes de converter valores, porque texto e número no Python não são sempre equivalentes. Se você tenta fazer operação matemática em string sem transformar o valor, o programa vai quebrar com um erro de tipo.

## 6. Formatação e Unicode: texto em português e além

Quando você quer mostrar dados ao usuário, a formatação da saída importa tanto quanto o cálculo em si. Em Python, `f-strings` são a forma mais clara de inserir valores dentro de uma frase.

<CodeBlock title="fstrings.py" code={`nome = "Camila"
idade = 27
altura = 1.68
print(f"{nome} tem {idade} anos e mede {altura:.2f} m")
print(f"Nome: {nome:>10}")
print(f"Total: R$ {1234.5:,.2f}")`} />

```text
Camila tem 27 anos e mede 1.68 m
Nome:    Camila
Total: R$ 1,234.50
```

A f-string é um jeito direto de incluir variáveis dentro do texto. O `:.2f` define duas casas decimais; `:>10` alinha o texto para a direita em um campo de largura 10; `:,.2f` formata valores com separador de milhar e duas casas decimais.

Também é importante entender a diferença entre <Glossario termo="Unicode" definition="Padrão que representa caracteres de muitos alfabetos, incluindo letras acentuadas do português." /> e a ideia de remover acentos. Python lidará bem com textos em português, mas em algumas situações você precisa normalizar o texto para comparar nomes ou gerar slugs em URL.

<Playground title="Experimente remover acentos" code={`import unicodedata

def remover_acentos(texto):
    return ''.join(
        caractere for caractere in unicodedata.normalize('NFD', texto)
        if unicodedata.category(caractere) != 'Mn'
    )

print(remover_acentos('São Paulo'))
print(remover_acentos('João da Silva'))`} />

```text
Sao Paulo
Joao da Silva
```

Esse recurso aparece muito em sistemas de cadastro, buscas e processamento de dados. Por exemplo, você pode ter um nome em uma base de dados com acento e outro sem, e mesmo assim quer tratá-los como equivalentes. A normalização de texto é um passo essencial para isso.

## 7. Erros comuns com strings

As strings são fáceis de usar, mas alguns erros acontecem com frequência. É melhor aprender cedo e evitar frustrações.

<Callout type="erro-comum" title="Erro comum 1: índice fora do intervalo">
  Código:
  <CodeBlock code={`texto = "Python"
print(texto[10])`} />
  Mensagem real:
  <pre>IndexError: string index out of range</pre>
  Correção: sempre cheque o tamanho antes de acessar uma posição específica, usando `len()`.
</Callout>

<Callout type="erro-comum" title="Erro comum 2: tentar alterar uma string no lugar">
  Código:
  <CodeBlock code={`texto = "Python"
texto[0] = "J"`} />
  Mensagem real:
  <pre>TypeError: 'str' object does not support item assignment</pre>
  Correção: strings são imutáveis; crie outra string usando `texto = "J" + texto[1:]`.
</Callout>

<Callout type="erro-comum" title="Erro comum 3: esquecer o retorno de replace">
  Código:
  <CodeBlock code={`texto = "Ana, Bia"
texto.replace(",", "|")
print(texto)`} />
  Mensagem real:
  <pre>Ana, Bia</pre>
  Correção: atribua o retorno da função: `texto = texto.replace(",", "|")`.
</Callout>
