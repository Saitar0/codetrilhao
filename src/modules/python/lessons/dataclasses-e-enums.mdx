# Dataclasses e enums

Crie estruturas mais claras com dataclasses e enumerações.

<Callout type="importante" title="Objetivo da aula">
  Neste bloco, você vai entender o conceito principal, ver exemplos práticos e testar a lógica em pequenos passos.
</Callout>

<CodeBlock title="exemplo_1.py" code={`from dataclasses import dataclass
@dataclass
class Item:
    nome: str
    preco: float
print(Item("Caneta", 4.9))`} />
<CodeBlock title="exemplo_2.py" code={`from enum import Enum
class Status(Enum):
    PENDENTE = "pendente"
    CONCLUIDO = "concluido"
print(Status.PENDENTE)`} />
<CodeBlock title="exemplo_3.py" code={`from dataclasses import dataclass
@dataclass(frozen=True)
class Produto:
    nome: str
print(Produto("Mouse"))`} />
