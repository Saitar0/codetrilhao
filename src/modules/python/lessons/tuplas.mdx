# Tuplas

Você já viu listas como coleções que podem mudar ao longo do tempo. Agora, quando o dado precisa ser fixo, Python oferece uma estrutura mais rígida: a <Glossario termo="tupla" definition="Sequência ordenada e imutável de valores em Python." />. Em vez de pensar em "lista que cresce ou diminui", você pensa em "registro que representa uma entidade estável". Isso é muito útil para coordenadas, dados de usuário, pares de valores e retorno de funções.

Imagine que você está montando um sistema de cadastro. Um cliente pode ter nome, idade e cidade. Esse conjunto é mais claro se for tratado como uma estrutura fixa do que como uma lista que pode ser alterada por acidente. A tupla é a escolha certa quando a intenção do seu programa é dizer: "esses dados pertencem juntos e não devem mudar sem pensar".

<Callout type="importante" title="O que você vai aprender">

  - Como usar desempacotamento para receber vários valores de uma vez.
  - Quando a tupla é melhor do que uma lista para representar dados fixos.
  - Como a imutabilidade evita alterações acidentais.
  - Como retornar múltiplos valores de uma função usando tuplas.
</Callout>

## 1. O que é uma tupla?

Uma tupla é uma sequência ordenada como a lista, mas ela é <Glossario termo="imutável" definition="Valor que não pode ser alterado depois de criado." />. Isso significa que você não pode trocar um item no meio dela, inserir um novo valor ou remover um existente depois que a tupla foi criada. O código fica mais explícito: se um dado representa um conjunto fixo, a tupla comunica essa intenção para você e para outras pessoas lendo o programa.

A sintaxe é simples: os elementos ficam entre parênteses, separados por vírgulas.

<CodeBlock title="tupla_basica.py" code={`ponto = (10, 20)
print(ponto)
print(ponto[0])
print(ponto[1])`} />

```text
(10, 20)
10
20
```

Você também pode criar uma tupla vazia com `()`, mas ela tem pouco uso prático. O caso mais comum é uma sequência de valores com significado relacionado, como um ponto em um plano, uma data com dia e mês, ou um registro de pessoa.

<CodeBlock title="tupla_registro.py" code={`usuario = ("Ana", 29, "SP")
print(usuario)
print(usuario[0])
print(usuario[2])`} />

```text
('Ana', 29, 'SP')
Ana
SP
```

Observe que a tupla guarda a ordem dos elementos e você pode acessá-los por índice. Isso lembra a lista, mas a diferença está na flexibilidade: a tupla comunica que esse conjunto não deve mudar.

## 2. Desempacotamento: ler vários valores ao mesmo tempo

Uma das partes mais úteis da tupla é o <Glossario termo="desempacotamento" definition="Atribuição de vários valores de uma sequência para múltiplas variáveis em uma linha." />. Em vez de escrever `nome = dados[0]`, `idade = dados[1]`, você faz em uma única instrução.

<CodeBlock title="desempacotamento.py" code={`nome, idade, cidade = ("Ana", 29, "São Paulo")
print(nome)
print(idade)
print(cidade)`} />

```text
Ana
29
São Paulo
```

Esse padrão aparece bastante em programas reais, especialmente quando você trabalha com uma função que devolve vários valores. O Python aceita `a, b, c = tupla` quando o número de elementos combina com o número de variáveis. Se os tamanhos forem diferentes, você recebe um erro.

<CodeBlock title="troca_de_valores.py" code={`a, b = 10, 20
a, b = b, a
print(a)
print(b)`} />

```text
20
10
```

A troca de valores usando tupla é um truque clássico em Python. Em vez de criar uma variável temporária, você reescreve a tupla com os valores invertidos. Isso deixa o código curto e legível.

## 3. Tupla como retorno de função

Quando uma função precisa devolver duas ou mais informações, a tupla é uma escolha natural. Ela mantém uma relação clara entre os valores e deixa a função mais simples de usar. Em vez de retornar uma lista mutável, você retorna uma estrutura fixa que transmite intenção.

<CodeBlock title="retorno_multiplo.py" code={`def dados_pessoa():
    return ("Bruno", 31)

nome, idade = dados_pessoa()
print(f"{nome} tem {idade} anos")`} />

```text
Bruno tem 31 anos
```

Esse padrão é muito comum em funções de processamento de dados. Por exemplo, você pode escrever uma função que calcula a menor e a maior temperatura em um conjunto de valores e retorna ambas em uma tupla. O chamador desempacota os resultados e usa diretamente.

<StepThrough>
  <div>
    <p>Primeiro, a função calcula uma tupla com os resultados.</p>
    <CodeBlock title="tupla_step_1.py" code={`def calcular_media_e_total(notas):
    total = sum(notas)
    media = total / len(notas)
    return (total, media)

resultado = calcular_media_e_total([7, 8, 9])
print(resultado)`} />
  </div>
  <div>
    <p>Depois, o chamador desempacota a tupla em variáveis separadas.</p>
    <CodeBlock title="tupla_step_2.py" code={`def calcular_media_e_total(notas):
    total = sum(notas)
    media = total / len(notas)
    return (total, media)

total, media = calcular_media_e_total([7, 8, 9])
print(total)
print(media)`} />
  </div>
  <div>
    <p>Assim, você trabalha com dados organizados sem mexer em uma lista mutável.</p>
    <CodeBlock title="tupla_step_3.py" code={`def calcular_media_e_total(notas):
    total = sum(notas)
    media = total / len(notas)
    return (total, media)

total, media = calcular_media_e_total([7, 8, 9])
print(f"Total: {total}")
print(f"Média: {media:.1f}")`} />
  </div>
</StepThrough>

```text
(24, 8.0)
24
8.0
Total: 24
Média: 8.0
```

Esse padrão é um ótimo exemplo de como a tupla ajuda a deixar o código mais claro: o retorno é explícito e a chamada também fica elegante.

## 4. Quando usar tupla e quando usar lista?

A escolha entre lista e tupla não é aleatória. A lista é a estrutura de escolha quando a coleção precisa mudar: adicionar, remover, ordenar ou atualizar elementos. A tupla é melhor quando os dados representam uma unidade estável e sem alterações de rotina.

Um bom guia é este:

- Use <Glossario termo="lista" definition="Coleção mutável, ideal para dados que precisam mudar ao longo do tempo." /> quando a coleção vai crescer, diminuir ou ser reordenada.
- Use tupla quando o valor deve ser fixo e seu significado é mais do que apenas "uma sequência de itens".
- Em código de domínio, tuplas aparecem em coordenadas, registros de clientes e resultados de funções.

<Playground title="Experimento: tupla como registro" code={`dados = ("Carla", 26, "RJ")
nome, idade, cidade = dados
print(f"{nome} tem {idade} anos e mora no {cidade}.")`} />

<Playground title="Experimento: comparação rápida de lista e tupla" code={`lista = [1, 2, 3]
tupla = (1, 2, 3)
lista.append(4)
print(lista)
print(tupla)
print(tupla[0])`} />

A segunda experiência mostra a diferença prática: a lista aceita `append`, mas a tupla não. Isso que faz a tupla ser mais segura quando você não quer que o dado mude por acidente.

## 5. A imutabilidade como ferramenta de segurança

A maioria dos erros em programação não acontece porque o código é complicado demais, e sim porque o dado mudou em um ponto inesperado. A tupla ajuda a reduzir esse risco. Ela funciona como uma promessa: "este conjunto de dados foi pensado para ser estável".

Esse tipo de decision-making é muito comum em sistemas reais. Por exemplo, uma coordenada geográfica pode ser representada por `(nome, latitude, longitude)`. Talvez você queira listar esses pontos, classificá-los ou comparar distâncias, mas não alterar o valor original sem um novo cálculo. A tupla reduz o risco de mutação acidental.

No mercado de trabalho, essa ideia aparece em cadastros, processamento de eventos, integrações de APIs e análise de dados. Quando a estrutura de entrada é fixa, a tupla ajuda a modelar o problema de forma mais clara. Ela lembra o que um registro é em outras linguagens e é especialmente útil em áreas de dados e backend.

### No mercado de trabalho

Em empresas de tecnologia, tuplas são usadas para representar dados pequenos e bem definidos, como um par `(nome, valor)` ou uma coordenada `(latitude, longitude)`. Elas aparecem em APIs, processamento de arquivos, manipulação de dados em lote e em funções de suporte que devolvem vários resultados. Ao escolher tupla em vez de lista, você comunica ao time que aquele dado não deve sofrer alterações improvisadas.

Esse cuidado com a estrutura certa torna o código mais previsível, mais fácil de revisar e menos sujeito a bugs de estado.

<Callout type="erro-comum" title="TypeError: 'tuple' object does not support item assignment">
  Quando você tenta mudar um item dentro de uma tupla, o Python rejeita a operação porque ela é imutável.

  <CodeBlock title="tupla_erro.py" code={`ponto = (10, 20)
ponto[0] = 15
print(ponto)`} />

  ```text
  Traceback (most recent call last):
    File "tupla_erro.py", line 2, in <module>
      ponto[0] = 15
  TypeError: 'tuple' object does not support item assignment
  ```

  A correção é criar uma nova tupla com os valores desejados, por exemplo: `ponto = (15, 20)` ou `ponto = (ponto[0] + 5, ponto[1])`.
</Callout>
