# Operadores e expressões

Quando você escreve um programa, ele precisa combinar valores e decidir o que fazer com eles. Isso é o papel dos <Glossario termo="operadores" definition="Símbolos que executam operações sobre valores, variáveis ou expressões." /> e das <Glossario termo="expressões" definition="Combinações de valores, variáveis e operadores que produzem um resultado." />. Em outras palavras, operadores transformam dados; expressões organizam essa transformação em uma instrução que o Python consegue avaliar.

Imagine que você está calculando o total de uma compra, verificando se a idade permite votar e decidindo se um pedido pode ser enviado. Tudo isso depende de operadores e da ordem em que o Python resolve as operações. Sem entender isso, você passa a depender do “acaso” do código e acaba cometendo erros simples que são difíceis de rastrear.

<Callout type="importante" title="O que você vai aprender">
  - Entender os operadores aritméticos mais usados em Python.
  - Saber usar atribuição composta e comparações em expressões válidas.
  - Combinar condições com `and`, `or` e `not` sem confundir lógica.
  - Reconhecer a diferença entre pertencimento e identidade.
  - Aplicar a precedência correta, com parênteses quando necessário.
</Callout>

## 1. Operadores aritméticos: transformar valores

Os operadores aritméticos são os mais fáceis de visualizar na prática. Eles fazem cálculos com números e devolvem um resultado.

<CodeBlock title="aritmetica_basica.py" code={`a = 10
b = 3
print(a + b)
print(a - b)
print(a * b)
print(a / b)
print(a // b)
print(a % b)
print(a ** b)`} />

```text
13
7
30
3.3333333333333335
3
1
1000
```

Aqui você vê alguns operadores muito importantes:

- `+` para soma.
- `-` para subtração.
- `*` para multiplicação.
- `/` para divisão real, que produz `float`.
- `//` para divisão inteira, descartando o resto.
- `%` para resto da divisão, muito útil em cálculos de paridade e divisibilidade.
- `**` para potência.

A divisão inteira e o módulo aparecem em vários problemas de lógica. Por exemplo, se você quer saber se um número é par, pode testar `n % 2 == 0`. Se quiser separar horas, minutos e segundos, `//` e `%` são ferramentas enormes.

## 2. Atribuição composta: atualizar um valor sem reescrever tudo

Python também oferece operadores de atribuição composta, como `+=`, `-=`, `*=`, `/=` e `%=`. Eles servem para atualizar uma variável a partir do valor atual, sem escrever a variável duas vezes.

<CodeBlock title="atribuicao_composta.py" code={`saldo = 100
saldo += 15
saldo *= 2
print(saldo)`} />

```text
230
```

Esse código faz o seguinte: começa com `saldo = 100`; depois `saldo += 15` vira `115`; por fim `saldo *= 2` vira `230`. É só uma forma mais curta de escrever a mesma ideia. Isso deixa o código mais claro quando você está alterando um valor várias vezes no mesmo bloco.

## 3. Comparação: verificar relações entre valores

Operadores de comparação devolvem `True` ou `False`. Eles são a base das decisões em Python. Quando você compara valores, está perguntando: “isso é igual?”, “isso é maior?”, “isso está entre dois limites?”.

<CodeBlock title="comparacao_basica.py" code={`idade = 18
print(idade == 18)
print(idade != 18)
print(idade < 21)
print(idade >= 18)
print(0 < idade < 21)`} />

```text
True
False
True
True
True
```

A expressão `0 < idade < 21` é um exemplo muito útil: em Python, ela funciona como “maior que 0 e menor que 21”. Em vez de escrever duas comparações separadas, você pode encadear a condição de forma mais legível. Isso é muito comum em validações e filtros.

A leitura da expressão também importa. `idade == 18` significa “a idade é igual a 18?” e não “atribua 18 a idade”. Essa diferença é um ponto clássico de erro em Python, e vale reforçar.

## 4. Operadores lógicos: combinar condições

Os operadores lógicos são `and`, `or` e `not`. Eles permitem montar condições mais complexas, por exemplo: “tem idade mínima e possui documento” ou “é maior de idade ou está acompanhado”.

<CodeBlock title="operadores_logicos.py" code={`idade = 18
tem_cartao = True
tem_veiculo = False

print(idade >= 18 and tem_cartao)
print(idade >= 18 or tem_veiculo)
print(not tem_veiculo)`} />

```text
True
True
True
```

O operador `and` exige que todas as partes sejam verdadeiras. O `or` exige apenas uma. Já o `not` inverte o valor booleano: se algo é `True`, `not` transforma em `False`.

Uma parte importante do Python é o <Glossario termo="curto-circuito" definition="Quando a avaliação da expressão para antes de testar tudo, porque o resultado já ficou definido." />. Por exemplo, em `False and (1 / 0)`, o Python não tenta dividir por zero, porque `False and ...` já é falso independentemente do restante. Isso evita erros desnecessários e torna expressões lógicas muito eficientes.

<Playground title="Experimente a lógica com condições" code={`idade = 20
status = 'ativo'
print(idade >= 18 and status == 'ativo')
print(idade < 18 or status == 'ativo')
print(not (idade < 18))`} />

## 5. Pertencimento e identidade: saber se algo existe ou se é o mesmo objeto

Além dos operadores aritméticos, de comparação e lógicos, Python tem operadores de pertencimento e identidade. Eles parecem parecidos, mas têm papéis diferentes.

- `in` e `not in`: verificam se um valor está dentro de outra estrutura, como texto ou lista.
- `is` e `is not`: verificam se duas variáveis apontam para o mesmo objeto na memória.

<CodeBlock title="pertencimento_e_identidade.py" code={`texto = "Python"
lista = [1, 2, 3]

print("Py" in texto)
print("x" not in texto)
print(2 in lista)

x = [1, 2]
y = x
z = [1, 2]
print(x is y)
print(x is z)`} />

```text
True
True
True
True
False
```

Esse exemplo mostra uma diferença importante: `x is y` é `True` porque `y` recebe a mesma lista de `x`. Já `x is z` é `False` porque `z` é outra lista, mesmo com os mesmos valores. Em outras palavras, igualdade de conteúdo e identidade de objeto são coisas diferentes.

## 6. Precedência: a ordem em que Python resolve expressões

A precedência define qual parte da expressão o Python calcula primeiro. Se você não souber a regra, pode escrever algo que parece óbvio e obter um resultado completamente diferente do esperado.

<Tabela data={[
  ['Ordem', 'Operadores', 'Exemplo', 'Observação'],
  ['1', 'Parênteses', '(2 + 3) * 4', 'O que estiver dentro de parênteses é resolvido primeiro.'],
  ['2', 'Expoentes', '2 ** 3', 'Potenciação tem prioridade alta.'],
  ['3', 'Unários', '-x, +x, ~x', '-3 * 2', 'Sinais e negação possuem precedência alta.'],
  ['4', 'Multiplicação e divisão', '* / // %', '2 + 3 * 4', 'Essas operações vêm antes da soma.'],

  ['6', 'Comparações', '< <= > >= == !=', '5 < x < 10', 'Comparações aparecem antes dos operadores lógicos.'],
  ['7', 'not', 'not x', 'not idade > 18', 'Inverte a condição.'],
  ['8', 'and', 'a and b', 'cond1 and cond2', 'Exige que todas as condições sejam verdadeiras.'],
  ['9', 'or', 'a or b', 'cond1 or cond2', 'Basta uma condição verdadeira para o resultado ser True.'],
  ['10', 'Atribuição', '=', 'total = 2 + 3', 'Atribui o resultado final ao nome da variável.'],
]} />

Essa tabela é a regra de ouro para não errar expressões. Você não precisa decorar tudo de memorizar, mas precisa ter esse mapa em mente e usar parênteses para deixar a hierarquia explícita. Quando a expressão fica confusa, escreva os parênteses para clareza.

<Playground title="Compare precedência com e sem parênteses" code={`x = 2 + 3 * 4
print(x)

y = (2 + 3) * 4
print(y)`} />

  </div>

## 7. `%` e `//`: truques que aparecem muito em lógica

Os operadores `%` e `//` costumam causar confusão no início, mas eles são muito úteis. `//` devolve a parte inteira da divisão. `%` devolve o resto.

<CodeBlock title="divisao_inteira_e_resto.py" code={`segundos = 3725
horas = segundos // 3600
minutos = (segundos % 3600) // 60
resto = segundos % 60
print(f"{horas}h {minutos}min {resto}s")` } />

```text
1h 2min 5s
```

Esse exemplo mostra como transformar um total de segundos em horas, minutos e segundos. Quando você usa `%`, a ideia é “qual é o resto depois de tirar todos os grupos completos?”. Esse raciocínio aparece em vários exercícios, desde cálculo de parcelas até números pares e divisíveis por 3.

A combinação de `%` e `//` também aparece em problemas clássicos de lógica, como separar unidade, dezena e centena de um número ou descobrir se um número é múltiplo de 5. Esse é um tipo de operação muito útil em sistemas de RH, vendas, logística e finanças, porque ela traduz regras numéricas complexas em cálculos simples.

## Erros comuns

<Callout type="erro-comum" title='Usar `=` no lugar de `==`'>
  <CodeBlock title="operador_igualdade.py" code={`idade = 18
print(idade = 18)`} />
  <p>Esse erro acontece porque `=` atribui valor e `==` compara. Em Python, o código lê como “atribuir 18 a idade”, o que não faz sentido dentro de um `print`.</p>
  <p>Correção: use `==` quando a intenção for verificar igualdade.</p>
  <CodeBlock title="operador_igualdade_corrigido.py" code={`idade = 18
print(idade == 18)`} />
</Callout>

<Callout type="erro-comum" title='`x > 5 and < 10`'>
  <CodeBlock title="operador_incompleto.py" code={`x = 7
print(x > 5 and < 10)`} />
  <p>Esse trecho está incompleto, porque o Python precisa comparar `< 10` com algum valor. A sintaxe não é válida e o erro aparece imediatamente.</p>
  <p>Correção: escreva a comparação completa, como `5 < x < 10`.</p>
  <CodeBlock title="operador_incompleto_corrigido.py" code={`x = 7
print(5 < x < 10)`} />
</Callout>

<Callout type="erro-comum" title='Resultado inesperado com `not` e `and`'>
  <CodeBlock title="precedencia_not.py" code={`idade = 30
print(not idade > 18 and idade < 40)`} />
  <p>Esse código produz `False`, mesmo parecendo “idade entre 18 e 40”. Isso acontece porque `not` tem precedência maior do que `and`.</p>
  <p>Correção: use parênteses para deixar a intenção explícita, como `not (idade > 18 and idade < 40)`.</p>
  <CodeBlock title="precedencia_not_corrigido.py" code={`idade = 30
print(not (idade > 18 and idade < 40))` } />
</Callout>

## No mercado de trabalho

Operadores e expressões aparecem em quase qualquer sistema. Em um e-commerce, você pode calcular imposto, avaliar se o pedido tem frete grátis e decidir se a compra está dentro de uma promoção. Em uma plataforma de RH, você usa comparações para decidir se uma pessoa é elegível para férias ou um benefício. Numa aplicação bancária, expressões lógicas validam regras de transação, limite, risco e autenticação.

Isso significa que, embora pareçam simples, operadores são uma base crítica para a lógica de negócios. Quando a expressão está bem estruturada, o programa fica fácil de testar, fácil de manter e mais difícil de quebrar. Em vez de “só funcionar”, você passa a escrever condições que podem ser lidas e revisadas por outra pessoa.
