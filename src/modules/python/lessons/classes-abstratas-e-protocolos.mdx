# Classes abstratas e protocolos

Defina contratos e interfaces para organizar código maior.

<Callout type="importante" title="Objetivo da aula">
  Neste bloco, você vai entender o conceito principal, ver exemplos práticos e testar a lógica em pequenos passos.
</Callout>

<CodeBlock title="exemplo_1.py" code={`from abc import ABC, abstractmethod
class Animal(ABC):
    @abstractmethod
    def falar(self):
        pass
class Gato(Animal):
    def falar(self):
        return "miau"
print(Gato().falar())`} />
<CodeBlock title="exemplo_2.py" code={`from typing import Protocol
class Pagavel(Protocol):
    def pagar(self, valor: float) -> None: ...
print(Pagavel)`} />
<CodeBlock title="exemplo_3.py" code={`class Boleto:
    def pagar(self, valor: float) -> None:
        print(valor)`} />
