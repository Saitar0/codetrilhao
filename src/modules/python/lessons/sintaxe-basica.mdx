# Sintaxe básica do Python

A sintaxe de uma linguagem é a forma correta de escrever instruções para que o computador entenda. Em Python, a leitura do código é simples e direta, mas existem elementos muito importantes: a indentação, os comentários e a estrutura de blocos. Entender isso logo no início evita muitos erros frustrantes.

<Callout type="importante" title="O que você vai aprender">
  - Entender a estrutura básica de um programa Python.
  - Usar `print()` com argumentos, `sep` e `end`.
  - Aprender a importância da indentação e dos comentários.
  - Identificar e corrigir erros comuns de sintaxe.
</Callout>

## 1. A estrutura mínima de um programa

Todo programa em Python começa com instruções em sequência. Uma instrução simples pode ser apenas um comando de saída:

<CodeBlock title="ola.py" code={`print("Olá, mundo!")`} />

Saída esperada:

```text
Olá, mundo!
```

O `print()` é o comando mais clássico para exibir texto na tela. Ele é tão importante porque ajuda você a ver se o programa está funcionando e o que cada parte do código está fazendo.

## 2. `print()` com vários argumentos, `sep` e `end`

O `print()` aceita mais de um valor ao mesmo tempo. Isso é útil quando você quer mostrar várias informações em uma linha.

<CodeBlock title="print_variados.py" code={`print("Python", "é", "legível")
print("A", "B", "C", sep=" | ")
print("Olá,", "mundo!", end="\n\n")
print("Fim")`} />

Saída esperada:

```text
Python é legível
A | B | C
Olá, mundo!

Fim
```

Aqui você vê três nuances importantes:

- `print("Python", "é", "legível")` imprime vários argumentos separados por espaço;
- `sep=" | "` troca o separador padrão por uma string que você escolhe;
- `end="\n\n"` altera o caractere final da linha, o que pode criar espaços extras.

Essa é uma das primeiras formas de deixar a saída mais legível e profissional.

## 3. Comentários e docstrings de uma linha

Comentários são trechos ignorados pelo Python, mas muito úteis para explicar o código. Eles começam com `#`.

<CodeBlock title="comentarios.py" code={`# Isso é um comentário
nome = "Ana"
print("Bem-vinda,", nome)`} />

Saída esperada:

```text
Bem-vinda, Ana
```

Uma docstring de uma linha funciona como uma descrição curta do código e pode ser usada em alguns contextos, mas o mais comum no começo da jornada é o comentário com `#`.

<CodeBlock title="docstring.py" code={`"""Programa de boas-vindas."""
print("Olá, estudante!")`} />

Saída esperada:

```text
Olá, estudante!
```

Comentários e descrições ajudam você e outras pessoas a entender a lógica do código sem precisar “adivinhar” o que cada parte faz.

## 4. Indentação como parte da sintaxe

Uma das regras mais importantes de Python é a indentação. Em outras linguagens, chaves `{}` e blocos de código marcam a estrutura. Em Python, o que define um bloco é a quantidade de espaços da linha.

Veja um exemplo simples:

<CodeBlock title="indentacao.py" code={`idade = 18
if idade >= 18:
    print("Você é maior de idade")
    print("Pode entrar")
print("Programa finalizado")`} />

Saída esperada:

```text
Você é maior de idade
Pode entrar
Programa finalizado
```

Veja que as linhas dentro do `if` ficam com 4 espaços de indentação. Isso é obrigatório. Se você misturar espaços e tabs, ou se a indentação estiver errada, o Python vai acusar um erro.

<StepThrough>
  <div>
    <strong>Passo 1</strong>
    <p>O Python lê a linha com o comando <code>if idade >= 18:</code>.</p>
  </div>
  <div>
    <strong>Passo 2</strong>
    <p>Ele entende que o bloco seguinte pertence ao `if` porque está recuado em 4 espaços.</p>
  </div>
  <div>
    <strong>Passo 3</strong>
    <p>Quando termina o bloco, o programa continua e imprime a linha final.</p>
  </div>
</StepThrough>

A indentação não é só estética; ela é parte da estrutura do programa. Isso é um detalhe que parece simples, mas é essencial para escrever código em Python corretamente.

## 5. Erros comuns de sintaxe

A primeira coisa que você vai aprender ao programar é que erro não é fracasso; é informação. Python costuma mostrar uma mensagem clara que ajuda a localizar o problema. Os erros mais comuns neste início são `SyntaxError`, `IndentationError` e `NameError`.

<Callout type="erro-comum" title="SyntaxError: unterminated string">
  <CodeBlock title="erro_string.py" code={`print("Olá, mundo!)`} />
  <p>Mensagem real do erro no Python 3:</p>
  <pre>SyntaxError: unterminated string literal (detected at line 1)</pre>
  <p>Correção: feche a aspa antes de encerrar a string.</p>
</Callout>

<Callout type="erro-comum" title="IndentationError">
  <CodeBlock title="erro_indentacao.py" code={`idade = 18
if idade >= 18:
print("Maior de idade")`} />
  <p>Mensagem real do erro no Python 3:</p>
  <pre>IndentationError: expected an indented block after 'if' statement on line 2</pre>
  <p>Correção: use 4 espaços de indentação dentro do bloco.</p>
</Callout>

<Callout type="erro-comum" title="NameError: name 'Print' is not defined">
  <CodeBlock title="erro_nome.py" code={`Print("Olá")`} />
  <p>Mensagem real do erro no Python 3:</p>
  <pre>NameError: name 'Print' is not defined</pre>
  <p>Correção: use a função correta, que é `print` em minúsculas.</p>
</Callout>

Esse conjunto de erros vai aparecer bastante no começo. Você não precisa decorar tudo; o que importa é aprender a ler a mensagem de baixo para cima no traceback e entender que a última linha geralmente mostra a causa mais direta.

## No mercado de trabalho

Na prática profissional, a sintaxe correta é o que permite a equipe entender e manter um projeto. Quem escreve Python de forma legível e organizada reduz retrabalho, facilita revisão e evita bugs simples. A indentação, por exemplo, não é um detalhe de gosto: ela faz parte da linguagem e impacta diretamente a execução do programa.

Além disso, a capacidade de ler erros e mensagens do interpretador é parte do processo real de desenvolvimento. Em qualquer ambiente de trabalho, você vai encontrar mensagens de erro, e a habilidade de interpretá-las é um sinal de maturidade técnica.
