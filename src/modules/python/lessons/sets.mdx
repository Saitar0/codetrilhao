# Sets

Depois de entender listas e tuplas,Você chega a uma estrutura que muda a lógica de pensar em dados: o <Glossario termo="set" definition="Coleção não ordenada de elementos únicos em Python." />. A ideia central do conjunto é simples e muito útil: ele guarda elementos sem duplicatas e facilita comparações entre grupos. Se você quer descobrir quem está em ambos os grupos, quem está só em um deles, ou remover itens repetidos rapidamente, o set é uma ferramenta quase perfeita.

Imagine que você está trabalhando com cadastro de alunos, lista de participantes de um evento ou base de e-mails. Em todos esses casos, você precisa saber o que é único, o que se repete e o que está em comum entre dois grupos. A estrutura de conjunto resolve isso com operações bem diretas e legíveis.

<Callout type="importante" title="O que você vai aprender">
  - Como criar um set e entender que ele não guarda duplicatas.
  - Como usar `in` para testar presença rápida.
  - Como operar com `|`, `&`, `-` e `^` para união, interseção e diferença.
  - Como usar `add`, `discard` e `remove` para editar o conjunto.
  - Quando usar set em vez de lista ou tupla, e como escolher a estrutura certa.
</Callout>

## 1. O que é um set?

Um conjunto em Python é uma coleção de elementos únicos, sem ordem garantida e sem índices. Isso significa que, ao contrário de uma lista, você não acessa elementos por posição como `lista[0]`. Em vez disso, o conjunto é pensado para pertencimento e comparação: “este item está dentro do conjunto?”

Para criar um set, você usa chaves `{}` com elementos separados por vírgulas. Se tiver itens repetidos, o Python guarda apenas uma cópia.

<CodeBlock title="set_basico.py" code={`frutas = {"maçã", "banana", "maçã", "uva"}
print(frutas)
print("maçã" in frutas)
print("laranja" in frutas)`} />

```text
{'maçã', 'uva', 'banana'}
True
False
```

A saída mostra duas coisas importantes: primeiro, o conjunto não preserva duplicatas; segundo, a ordem não é garantida. Em um conjunto, a organização interna não importa: o que importa é a presença ou ausência de cada item. Isso é muito diferente de lista, que preserva ordem e permite duplicata.

## 2. Operações entre conjuntos

O grande diferencial do set é a riqueza de operações para comparar grupos. Python oferece operadores bem claros para União, Interseção, Diferença e Diferença Simétrica.

<CodeBlock title="operacoes_set.py" code={`turma_a = {"Ana", "Bruno", "Carla"}
turma_b = {"Bruno", "Diego"}

print(turma_a | turma_b)  # união
print(turma_a & turma_b)  # interseção
print(turma_a - turma_b)  # só em A
print(turma_a ^ turma_b)  # em um ou outro, mas não nos dois`} />

```text
{'Ana', 'Bruno', 'Carla', 'Diego'}
{'Bruno'}
{'Ana', 'Carla'}
{'Ana', 'Carla', 'Diego'}
```

Esses operadores são muito úteis em lógicas de comparação:

- `|` cria a união: todos os elementos que aparecem em qualquer um dos conjuntos.
- `&` cria a interseção: só os elementos que aparecem nos dois.
- `-` cria a diferença: itens presentes em A que não estão em B.
- `^` cria a diferença simétrica: itens presentes em um conjunto ou no outro, mas não nos dois ao mesmo tempo.

Você pode pensar em cada operação como uma pergunta que o programa faz sobre os grupos. Isso faz do set uma estrutura ótima para análise de população, listas de amigos, deduplicação de usuários e cruzamento de dados.

## 3. Modificando um conjunto

Além de comparar, você também pode adicionar e remover elementos. Os métodos mais comuns são `add`, `discard` e `remove`.

<CodeBlock title="modificando_set.py" code={`participantes = {"Maria", "Pedro"}
participantes.add("João")
participantes.add("Maria")
participantes.discard("Pedro")
print(participantes)

participantes.remove("João")
print(participantes)`} />

```text
{'Maria', 'João'}
{'Maria'}
```

A diferença entre `discard` e `remove` é importante:

- `add(valor)` acrescenta um item novo.
- `discard(valor)` remove se existir, sem erro se não existir.
- `remove(valor)` remove se existir e dispara erro se não existir.

A escolha depende do tipo de relaxamento que você quer no código. `discard` é mais seguro quando o valor pode não existir; `remove` é útil quando você espera que o item esteja presente e quer detectar problema imediatamente.

## 4. `frozenset`: a versão imutável do set

Existe também o <Glossario termo="frozenset" definition="Versão imutável de um conjunto, que não permite alterações depois da criação." />. Ele funciona como um set normal, mas sem `add` ou `remove`.

<CodeBlock title="frozenset_exemplo.py" code={`conjunto = frozenset({"A", "B", "C"})
print(conjunto)
print("A" in conjunto)
# conjunto.add("D")  # isso causaria erro`} />

```text
frozenset({'A', 'B', 'C'})
True
```

O `frozenset` aparece em cenários em que você quer uma coleção imutável para usar como chave ou como valor fixo em outra estrutura. Isso torna ainda mais clara a diferença entre "dados que podem mudar" e "dados que representam identidade ou regra estática".

## 5. Quando usar lista, tupla ou set?

A decisão de estrutura certa é uma parte central da programação. A tabela abaixo resume o comportamento das três estruturas que você viu até agora.

<Tabela data={[
  ['Estrutura', 'Ordenada', 'Mutável', 'Duplicatas', 'Uso típico'],
  ['lista', 'sim', 'sim', 'sim', 'coleção que muda ao longo do tempo'],
  ['tupla', 'sim', 'não', 'sim', 'registro fixo, coordenadas, retorno múltiplo'],
  ['set', 'não', 'sim', 'não', 'unicidade, comparação de grupos e deduplicação'],
]} />

A diferença principal é esta:

- Lista: mantém ordem e permite alterar os elementos.
- Tupla: mantém ordem, mas não permite alteração.
- Set: não mantém ordem e ignora duplicatas.

Essa distinção é mais importante do que parece. O código fica mais legível quando a estrutura combina com a intenção do dado. Se você quer uma fila de tarefas, use lista. Se quer representar um ponto fixo, use tupla. Se quer descobrir pertencimento, interseções e exclusões, use set.

<Playground title="Experimento: remover duplicatas" code={`emails = ["ana@exemplo.com", "bruno@exemplo.com", "ana@exemplo.com", "carla@exemplo.com"]
sem_duplicatas = set(emails)
print(sem_duplicatas)
print(len(emails), len(sem_duplicatas))`} />

<Playground title="Experimento: comparação de grupos" code={`alunos_a = {"Ana", "Bruno", "Carla"}
alunos_b = {"Bruno", "Diego", "Eva"}
print("Em comum:", alunos_a & alunos_b)
print("Só em A:", alunos_a - alunos_b)
print("Só em B:", alunos_b - alunos_a)`} />

A primeira experiência mostra como set elimina duplicatas de forma nativa. A segunda mostra que o conjunto trabalha muito bem para cruzar dados e responder perguntas de comparação sem escrever código muito longo.

## 6. Armadilhas comuns

Mesmo com operações simples, alguns erros aparecem com frequência.

<Callout type="erro-comum" title="{} vira dicionário, não set">
  Quando você escreve `{}` vazio, o Python cria um dicionário, não um conjunto. Isso causa confusão porque a sintaxe parece parecida.

  <CodeBlock title="set_vazio_ambiguidade.py" code={`vazio = {}
print(type(vazio))
print(vazio)

conjunto_vazio = set()
print(type(conjunto_vazio))`} />

  ```text
  <class 'dict'>
  {}
  <class 'set'>
  set()
  ```

  Se você quer um conjunto vazio, use `set()`. Já `{}` significa dicionário vazio, que tem pares chave-valor em vez de valores isolados.
</Callout>

<Callout type="erro-comum" title="Esperar ordem em um set">
  Um conjunto não garante ordem, então não faça suposições como “o primeiro elemento será o menor” ou “os itens aparecem na ordem em que foram adicionados”.

  <CodeBlock title="set_ordem_inesperada.py" code={`numeros = {7, 2, 9, 1}
print(numeros)
print(sorted(numeros))`} />

  ```text
  {1, 2, 7, 9}
  [1, 2, 7, 9]
  ```

  Caso você precise uma ordem previsível, transforme o conjunto em lista e ordene com `sorted()`.
</Callout>

Essa sequência ajuda a visualizar que o set é uma ferramenta de comparação, não de indexação. Você não vai “pegar o segundo item” de um conjunto; você vai perguntar se um item existe, quais itens são compartilhados e quais são exclusivos.

### No mercado de trabalho

Conjuntos aparecem em processos de deduplicação, filtros, comparação de listas e análise de dados. Empresas usam set em campanhas de marketing, CRM, sistemas de autenticação, checagem de permissões e automações que precisam saber rapidamente se um usuário ou item já foi visto antes. Em dados, a interseção e a diferença são operações muito comuns quando você cruza informações de fontes diferentes.

A velocidade de busca e a simplicidade de operações de comparação tornam o set uma estrutura extremamente útil em código que trabalha com altas quantidades de itens e precisa responder perguntas como “este valor existe?” ou “quais elementos estão em ambos os grupos?”.
