# Context managers

Controle elementos de recursos com a sintaxe do with.

<Callout type="importante" title="Objetivo da aula">
  Neste bloco, você vai entender o conceito principal, ver exemplos práticos e testar a lógica em pequenos passos.

<CodeBlock title="exemplo_1.py" code={`with open("arquivo.txt", "w", encoding="utf-8") as f:
    f.write("texto")`} />
<CodeBlock title="exemplo_2.py" code={`from contextlib import contextmanager
@contextmanager
def abrir():
    print("abrindo")
    yield
    print("fechando")
with abrir():
    print("uso")`} />
<CodeBlock title="exemplo_3.py" code={`class Recurso:
    def __enter__(self):
        print("enter")
        return self
    def __exit__(self, exc_type, exc, tb):
        print("exit")
with Recurso():
    print("executando")`} />
