## aplicação prática

A ideia do tema aparece em automação, validação de dados, regras de negócio, análise de arquivos e manutenção de sistemas. O cenário muda, mas o raciocínio permanece: entenda a regra, teste um caso pequeno e confirme o resultado.

<CodeBlock title="metodos-especiais_exemplo_3.py" code={`idade = 18
print("Maior de idade" if idade >= 18 else "Menor de idade")`} />

```text
Maior de idade
```

<Callout type="erro-comum" title="Erro comum">
  ```python
  valores = [0, -1, 1]
  print(valores[0])
  ```

  Esse código funciona para o caso feliz, mas ignora limites e entradas inesperadas. Testar casos de borda ajuda a encontrar problemas que não aparecem em um cenário simples.
</Callout>
